THE `MEDIAN_L_OVER_B = 0.000000` IS REPORTED AS MEASURED AND IS NOT A DEFECT OF v2. It is 0 because
its NUMERATOR is 0: median(L) -- ADJ-2's aggregator over ALL 720 rows of the coordinate last-half
window -- is 0, since 403 of those 720 rows carry `topgun_or_prune_eligible_refs` = 0 (317 rows are
> 0, max 1000). The independently-computed census of the same window:

    parent rows m=720   non-sentinel B rows k=12   excluded=98.333333%   median(L)=0.000000
    (720 - 12) / 720 = 98.333333 %, which is the emitted fraction

WHAT v2 BOUGHT IS THE POINT R4.4 MAKES: the ratio is now GRADEABLE rather than structurally absent.
A published 0.000000 with its excluded fraction beside it is a reading of the evidence; v1's silence
was a reading of nothing. The window still routes to INDETERMINATE at 98.3 % via ADJ-12's EXISTING
`>50 %` hatch -- v2 does NOT implement that hatch and did not suppress anything above 50 %.

SUPPLEMENTARY -- R4.6's EMPTY-POPULATION BRANCH, EXERCISED (it is unreachable on this subject)
---------------------------------------------------------------------------------------------------
R4.6 is NORMATIVE and its state is LIVE for a repeat whose transient has already finished, but the
`spec356-long` window is 98.3 %-sentinel, not 100 %, so runs 1 and 2 CANNOT reach the branch. A
branch shipped untested is the same hazard in a smaller box, so v2's `B` block was extracted verbatim
(`spec356c-slottruth-v2.sh` lines 251-287 plus the closing brace) and run against three SYNTHETIC
fixtures. The fixtures are throwaway files under /tmp -- they are NOT committed, NOT evidence, and
NOT any of R3.5's dry-run CSVs; they exist only to reach the three arms of the emitted `B` path.

WHAT EACH ONE ESTABLISHES:

                         sentinel), the fraction is 100.000000, and `MEDIAN_L_OVER_B` is WITHHELD
