W7 — HOW #[cfg(test)] CODE WAS SCOPED OUT, VERIFIED EMPIRICALLY
--------------------------------------------------------------------------------

The file's test module DOES touch the map, so the scoping is load-bearing
rather than decorative. Verified at HEAD before the test was written and
re-verified at commit fd157593 after it landed (line numbers below are the
post-landing ones; none of the production sites moved):

  doc-comment / field-decl mentions    : 163 273 303 350 663 747 845 975 (+ test module)

SCOPING RULE ADOPTED: each scanned file is cut at the FIRST column-0
`#[cfg(test)]` attribute (`production_prefix`), and only the prefix is scanned.
For tombstone_frontier_impl.rs that cut is line 2802 — above every `state.`
access and above every test-module drain call. For crdt.rs it is line 1753 —
above the four test-module drain calls at :5387, :5846, :5893, :6149.

Two consequences relied on:
  (a) The scan does not have to distinguish `self.` from `state.` receivers by
      hand; the cut already removed every test access. Receiver-token filtering
      alone would have been fragile, because a future test could write `self.`
      inside an `impl` block in the test module.
  (b) The scanning literals may be spelled out. They live in the test module,
      BELOW the cut, so a scan that spells the thing it counts cannot count
      itself — the hazard this file's neighbouring structural test
      guards at :4252 by composing its needle instead.

The non-mutating reads are NOT miscounted as writers. Two of them are written
as broken method chains (`self` on one line, `.epoch_tags` on the next):
:727-728 `.get(&epoch)` and :956-958 `.keys()`. A naive scan for the literal
`self.epoch_tags` would have MISSED them entirely, and a scan for `epoch_tags.`
would have counted them as unclassified. Hence `flattened()`, which collapses
whitespace runs and rejoins ` .` to `.` before scanning. All five reads are then
classified by the verb that follows: `len` (:611), `contains_key` (:683),
`get` (:728), `keys` (:958), and the empty verb — the whole-map borrow at :1081,
`for (&epoch, refs) in &self.epoch_tags`.
